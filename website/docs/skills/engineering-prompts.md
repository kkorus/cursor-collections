# Prompt Engineering Patterns

**Skill name:** `tsh-engineering-prompts`  
**Source:** `src/skills/tsh-engineering-prompts/`  
**Used by:** Architect, Code Reviewer, Prompt Engineer

LLM prompt engineering patterns: structure, optimization, reasoning vs non-reasoning models, native tool calling, security, templates, evaluation, and anti-patterns.

**Use when** designing, writing, optimizing, or reviewing prompts for LLM applications (system prompts, user prompts, RAG templates, agent instructions, chatbot personas). NOT for authoring skills, agents or commands; use tsh-creating-skills, tsh-creating-agents or tsh-creating-commands for those.

## What it covers

- 1. Prompt Structure Patterns
- 2. Optimization Techniques
- 3. Reasoning and Non-Reasoning Models
- 4. Tool Use
- 5. Security Patterns
- 6. Templates and Evaluation
- 7. Anti-Patterns
