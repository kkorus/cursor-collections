# Analyzing Implementation Gaps

**Skill name:** `tsh-analyzing-implementation-gaps`  
**Source:** `src/skills/tsh-analyzing-implementation-gaps/`  
**Used by:** Architect, Code Reviewer, Plan Reviewer, Software Engineer, `tsh-implement-task` (step)

Compares a planned or expected change with the current state of the system and sorts the work into what is To Be Created, To Be Modified and To Be Reused, with file paths.

**Use when** checking a plan against existing code, deciding what to create, modify or reuse before implementing, or verifying how much of a plan is already implemented.
