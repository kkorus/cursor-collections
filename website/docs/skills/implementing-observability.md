# Observability Patterns

**Skill name:** `tsh-implementing-observability`  
**Source:** `src/skills/tsh-implementing-observability/`  
**Used by:** Architect, DevOps Engineer

Observability patterns for logging, monitoring, alerting, and distributed tracing.

**Use when** setting up monitoring and alerting, implementing centralized logging, metrics collection, or distributed tracing across services, designing SLOs/SLIs and error budgets, or creating dashboards and runbooks.

## What it covers

- Three Pillars of Observability
- Stack Detection
- Solution Decision Matrix
- Kubernetes Observability Pattern
- SLO/SLI Framework
- Alerting Strategy
- Structured Logging
- Process
- Checklist
- Anti-Patterns
- Summary Output
