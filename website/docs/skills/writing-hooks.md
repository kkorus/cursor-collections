# Writing Hooks

**Skill name:** `tsh-writing-hooks`  
**Source:** `src/skills/tsh-writing-hooks/`  
**Used by:** Software Engineer

Custom React hook patterns — naming, composition, stable return shapes, lifecycle cleanup, and testing strategies.

**Use when** writing reusable logic units as React hooks, refactoring logic into hooks, debugging hook behavior, or reviewing hook implementations.

## What it covers

- Hook Development Process
- Return Shape Guidelines
- Anti-Patterns
- Hook Quality Checklist
- Framework-Specific Patterns
