# Refactoring

**Skill name:** `tsh-refactoring`  
**Source:** `src/skills/tsh-refactoring/`  
**Used by:** Engineering Manager (orchestrator), `/tsh-refactor`

Behavior-preserving refactoring guidance - scoping, characterization tests, small verifiable steps and outcome verification.

**Use when** restructuring code without changing external behavior, extracting shared logic, reducing complexity, or cleaning up technical debt.

## What it covers

- Scope the refactoring
- Characterize current behavior
- Steps
- Verify the outcome
