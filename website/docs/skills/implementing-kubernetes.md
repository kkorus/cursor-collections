# Kubernetes Patterns

**Skill name:** `tsh-implementing-kubernetes`  
**Source:** `src/skills/tsh-implementing-kubernetes/`  
**Used by:** Architect, DevOps Engineer

Kubernetes deployment patterns, Helm charts, GitOps and cluster management.

**Use when** deploying applications to Kubernetes, designing Deployment, StatefulSet, or Job configurations, implementing auto-scaling (HPA, VPA, KEDA), creating or modifying Helm charts, setting up Gateway API routing and GitOps, or configuring resource requests, limits, and QoS.

## What it covers

- Project Detection
- Workload Type Decision
- Deployment Configuration
- Scaling Strategies
- Helm Chart Structure
- GitOps
- Traffic Routing
- Security Context
- Process
- Checklist
- Anti-Patterns
- Summary Output
