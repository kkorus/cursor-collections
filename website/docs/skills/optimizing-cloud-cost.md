# Cloud Cost Optimization

**Skill name:** `tsh-optimizing-cloud-cost`  
**Source:** `src/skills/tsh-optimizing-cloud-cost/`  
**Used by:** Architect, DevOps Engineer, `/tsh-analyze-cloud-costs`, `/tsh-audit-infrastructure`

Optimize cloud costs through resource rightsizing, tagging strategies, reserved instances, and spending analysis.

**Use when** reducing cloud spending or meeting budget constraints, right-sizing resources from utilization data, implementing cost governance and tagging, or analyzing multi-cloud cost optimization opportunities.
