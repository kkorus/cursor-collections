# Creating Skills

**Skill name:** `tsh-creating-skills`  
**Source:** `src/skills/tsh-creating-skills/`  
**Used by:** AI Customization Creator, AI Customization Reviewer, AI Customization Orchestrator (orchestrator), `/tsh-create-custom-skill`
