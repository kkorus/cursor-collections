# E2E Testing Patterns & Practices

**Skill name:** `tsh-writing-e2e-tests`  
**Source:** `src/skills/tsh-writing-e2e-tests/`  
**Used by:** E2E Engineer

E2E testing standards, patterns, verification procedures, and CI readiness checklists using Playwright.

**Use when** writing, debugging, or reviewing end-to-end tests, fixing flaky tests, creating Page Objects, or mocking external APIs. NOT for unit or integration tests.

## What it covers

- Process Checklist
- Standards
- Page Object Pattern
- Test Structure
- Authentication, Fixtures and Web Server
- Mocking (external APIs only)
- Verification Loop
- CI Readiness Checklist
- Summary
- Quick Reference
