# Implementing React

**Skill name:** `tsh-implementing-react`  
**Source:** `src/skills/tsh-implementing-react/`  
**Used by:** loaded on demand by any agent when the task matches its description

React implementation patterns covering the rules of hooks, effects and cleanup, state and composition, error boundaries, memoization with React 19 and the React Compiler, a hooks review checklist, and XSS-safe rendering with dangerouslySetInnerHTML.

**Use when** writing or reviewing React components and hooks, fixing effect bugs, deciding whether to memoize, or rendering untrusted content.

## What it covers

- Rules of Hooks
- Effects and Cleanup
- State, Composition and Error Boundaries
- Memoization, React 19 and the React Compiler
- Rendering Raw HTML (dangerouslySetInnerHTML and XSS)
- Hooks Review Checklist
- Anti-Patterns
