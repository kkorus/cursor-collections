# Multi-Cloud Architecture

**Skill name:** `tsh-designing-multi-cloud-architecture`  
**Source:** `src/skills/tsh-designing-multi-cloud-architecture/`  
**Used by:** Architect, DevOps Engineer

Design multi-cloud architectures using a decision framework to select and integrate services across AWS, Azure, and GCP.

**Use when** designing multi-cloud strategies, migrating between cloud providers, selecting cloud services for a workload, avoiding vendor lock-in, or leveraging best-of-breed services from multiple providers.
