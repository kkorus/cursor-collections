# Delivering Infrastructure

**Skill name:** `tsh-delivering-infrastructure`  
**Source:** `src/skills/tsh-delivering-infrastructure/`  
**Used by:** DevOps Engineer, `/tsh-audit-infrastructure`, Engineering Manager (orchestrator)

Shared delivery workflow for infrastructure work (Terraform, CI/CD, Kubernetes, observability, cloud cost, audits). Covers context discovery, the three-option output strategy, the FinOps threshold, the skill-loading table and the triggers that require an architect decision.

**Use when** implementing, changing or auditing infrastructure, pipelines, clusters or monitoring.

## What it covers

- Context discovery
- Skill loading
- Architect escalation
- Output strategy
- FinOps threshold
- Summary and audit outputs
